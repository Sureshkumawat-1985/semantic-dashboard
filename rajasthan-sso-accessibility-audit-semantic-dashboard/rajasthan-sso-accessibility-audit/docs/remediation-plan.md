# Remediation plan

Priorities are conditional until findings are verified.

1. **P0 / blocker:** Any confirmed keyboard trap, inaccessible CAPTCHA with no equivalent path, or inability to complete a core task.
2. **P1 / high:** Missing accessible names/instructions on required controls; inaccessible validation or authentication status.
3. **P2 / medium:** Contrast, focus visibility, responsive reflow, language and landmark issues that impair but do not fully block task completion.
4. **P3 / low:** Non-blocking consistency and maintainability improvements.

For each confirmed issue, create a ticket with: reproduction steps, evidence filename, affected WCAG success criterion, impact, proposed fix, owner, and retest result.
