# HTML validation

`semantic-dashboard.html` is a standalone HTML5 fixture reflecting the semantic structure and representative controls used by the React dashboard.

## Local check

```bash
npm install
npm run validate:html
```

## W3C Nu HTML Checker

Open https://validator.w3.org/nu/, choose the text input option, paste the contents of `semantic-dashboard.html`, and run the checker. Save the result page or screenshot alongside this README. A successful check should report no errors. The authoring environment could not resolve the validator host, so no W3C result is claimed here. Re-run the check after markup changes and inspect the rendered app as well.
